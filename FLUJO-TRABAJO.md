2. DESCRIPCIÓN INSTITUCIONAL 
Medicina Biológica Integral (MBI) es un centro de atención en salud con enfoque integrativo, 
cuyo modelo de trabajo combina diversas especialidades para abordar al paciente de manera 
personalizada. 
Áreas de atención: 
• Homeopatía biológica 
• Quiropraxia 
• Acupuntura 
• Naturopatía / Fitoterapia 
• Sueroterapia 
• Masaje terapéutico 
• Evaluaciones complementarias 
Modelo clínico: 
• Evaluación Integral MBI 
• Modelo 6+ (integración de terapias según el caso) 
3. OBJETIVO DEL PROYECTO 
Desarrollar un sistema web que permita: 
• centralizar la información clínica del paciente 
• gestionar múltiples especialidades con anamnesis diferenciadas 
• estructurar el proceso clínico real de MBI 
• integrar tratamiento, seguimiento y control 
• administrar citas, pagos y paquetes 
• implementar consentimiento informado trazable 
• generar reportes operativos y financieros 
• escalar el modelo a futuro 
4. ALCANCE DEL PROYECTO 
El proyecto se divide en dos componentes: 
4.1 Sistema interno (MBI Clinic) 
Sistema de gestión clínica, administrativa y de seguimiento. 
4.2 Plataforma web pública (MBI Web) 
Sitio institucional con capacidad de crecimiento y multisitio.

Tu documento ya contempla descripción de terapias, beneficios, riesgos, alternativas,

contenido del consentimiento

20. TEXTO EJECUTIVO FINAL PARA 
ENTREGAR 
MBI Clinic debe desarrollarse como un sistema clínico integral con expediente maestro 
único por paciente y formularios dinámicos según especialidad. El flujo clínico deberá 
respetar el orden real de atención de la clínica: anamnesis específica, evaluación por 
especialidad, evaluación integral MBI, integración clínica del caso, clasificación del 
paciente, recomendación de tratamiento, recomendación de paquete clínico, 
consentimiento, agenda y evolución. 
El módulo de quiropraxia deberá incluir un mapa corporal interactivo para registrar 
visualmente las zonas de dolor. El sistema deberá implementar un consentimiento híbrido: 
lectura del documento físico oficial disponible en clínica y validación digital mediante firma 
y huella dactilar, con trazabilidad completa y generación automática de comprobante 
digital.
